# 考研错题复习提醒系统

一个本地运行的考研学习复习辅助程序，帮助记录错题、管理章节、生成每日复习任务，并根据完成情况自动延期。

## 科目覆盖

- **数学课**：高等数学、线性代数、概率论
- **专业课**：数字电子技术

每个科目已**预置标准章节**（共 42 个，详见 `目录章节整理.md`），无需手动创建。

## 技术栈

- Python 3.10+
- Streamlit（Web UI）
- SQLite（数据持久化）

## 快速开始

### 安装并运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动应用
streamlit run app.py

# 3. 浏览器打开 http://localhost:8501
```

首次启动会自动创建数据库，并初始化 **4 个科目 + 42 个标准章节**，开箱即用。

### 使用流程（3 步上手）

1. **新增错题** — 录入你的错题（逐题录入 / 批量粘贴 / CSV 导入均可），无需手动设置复习日期，系统自动管理
2. **首页 → 生成今日任务** — 点击按钮，系统自动为每科生成最多 5 道复习题（按艾宾浩斯遗忘曲线 + 章节分散算法选取）
3. **今日复习** — 逐题复习，标记完成/错误/掌握，系统自动计算下次复习日期

> 章节已预置，无需手动创建。如需增删章节，可在「章节管理」页面操作。

## 核心功能

| 功能 | 说明 |
|------|------|
| 章节管理 | 预置 42 个标准章节（高等数学 18 / 线性代数 7 / 概率论 6 / 数字电子技术 11），支持自定义增删 |
| 错题录入 | 逐题录入 + 批量粘贴 + CSV 导入，复习日期由系统自动设定 |
| 错题库 | 多维度筛选（科目/章节/收藏/熟练/难度/关键词），支持编辑和删除 |
| 每日复习 | 每科每日自动生成 5 题，按优先级 + 章节分散算法选取 |
| 艾宾浩斯复习 | 答对按遗忘曲线递增间隔（1→2→4→7→15→30 天），答错重置为 1 天 |
| 延期机制 | 未完成任务自动延期至次日，次日优先出现 |
| 收藏/熟练 | 收藏题高优先级提醒，熟练题自动排除出复习池 |
| 统计总览 | 总错题/需复习/已复习/熟练/各科目进度/各章节进度 |
| 数据导出 | 错题 CSV 导出、复习记录 CSV 导出、数据库一键备份 |

## 每日任务生成规则

每科每日生成最多 5 道题，按优先级选取：

1. **延期题**（昨天及之前未完成的）—— 最高优先级
2. **收藏题**（已收藏且未熟练）—— 高优先级
3. **到期题**（系统计算的 next_review_date 已到达）
4. **补充题**（复习次数少、较久未复习的）

每科内部按**章节分散算法**轮询选取，尽量让 5 道题覆盖不同章节。熟练题不进入每日任务池。

### 艾宾浩斯遗忘曲线

| 连续答对次数 | 下次复习间隔 |
|-------------|-------------|
| 第 1 次 | 1 天后 |
| 第 2 次 | 2 天后 |
| 第 3 次 | 4 天后 |
| 第 4 次 | 7 天后 |
| 第 5 次 | 15 天后 |
| 第 6 次+ | 30 天后 |

答错时复习阶段重置，1 天后重新复习。

    ├── 1_今日复习.py          # 按科目分组展示任务，标记完成/错误/掌握
    ├── 2_新增错题.py          # 逐题录入 / 批量粘贴 / 编辑

    ├── 4_章节管理.py          # 按科目分组查看、新增、删除
    ├── 5_复习记录.py          # 历史复习记录查询
    ├── 6_数据统计.py          # 总览、按科目/章节下钻、题目筛选

## 数据备份

### 方法一：使用程序内备份

进入「数据导入导出」→「数据库备份」，点击按钮即可创建备份。

备份文件保存在 `data/backups/` 目录下。

### 方法二：手动备份

直接复制 `data/review.db` 文件到安全位置。

## CSV 导入格式

导入的 CSV 文件需包含以下列（带 `*` 的为必填）：

| 列名 | 必填 | 说明 |
|------|------|------|
| 题目标题 * | ✅ | 错题的简短标题 |
| 科目 * | ✅ | 必须是已存在的科目名 |
| 章节 | | 章节名，如不存在会自动创建 |
| 题目内容 | | 完整题目描述 |
| 错误原因 | | 分析错误原因 |
| 正确解法 | | 正确解题步骤 |
| 关键知识点 | | 涉及的知识点 |
| 来源 | | 真题/模拟题/习题册/课堂/自己整理 |
| 难度 | | 简单/中等/困难，默认中等 |
| 是否收藏 | | 1/是/True 表示收藏 |
| 是否熟练 | | 1/是/True 表示熟练 |
| 备注 | | 额外备注 |

## EXE 打包

如需生成独立的 .exe 文件（无需安装 Python 即可运行）：

```bash
# 确保已安装 Python 3.10+ 和 pip
# 然后运行打包脚本：
build_exe.bat
```

或手动打包：

```bash
pip install streamlit pyinstaller
pyinstaller --name="考研错题复习系统" --onefile --console --noconfirm \
    --add-data "pages;pages" --add-data "src;src" --add-data "app.py;." \
    --copy-metadata streamlit --copy-metadata watchdog \
    --copy-metadata pandas --copy-metadata numpy --copy-metadata pyarrow \
    --hidden-import=streamlit --hidden-import=streamlit.web.bootstrap \
    --hidden-import=streamlit.runtime --hidden-import=sqlite3 \
    --hidden-import=src.db --hidden-import=src.services \
    --hidden-import=src.task_scheduler --hidden-import=src.statistics \
    --hidden-import=src.import_export --hidden-import=src.utils \
    run_app.py
```

生成的 exe 位于 `dist/` 目录下。
